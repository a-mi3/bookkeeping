# GPT Images 2.0 インフォグラフィック生成プロンプト

```
日本語のインフォグラフィックを作成してください。

テーマ：「6月中旬、ピーマンの苗が小さくても大丈夫？」

【レイアウト】
- 縦長（1080×1350px、Instagram/note向け）
- 背景は薄い黄緑色のグラデーション
- 上部にタイトル、中央にメインコンテンツ、下部にまとめ

【タイトル（上部）】
大きな太字で：
「ピーマンの苗が小さい…失敗？」
その下に小さく：「→ プロに聞いたら "めちゃくちゃ順調" でした」

【セクション①：元気な苗のチェックポイント】
かわいいピーマンの苗のイラスト付きで3項目を縦に並べる：
✅ 葉が濃い緑色
✅ 節間が短くガッチリ
✅ 茎が太い
見出し：「健康な苗の3つのサイン」
背景色：薄い緑

【セクション②：収穫タイムライン】
横向きのタイムラインバーで：
6月 → 7月 → 8月 → 9月 → 10月
6月に「今ここ！まだ序盤」のラベル
下に「開花→収穫 たった2〜3週間」
背景色：薄いオレンジ

【セクション③：やること3つ】
横3列のカードレイアウト：
💧 水やりを切らさない（薄い青背景）
✂️ 1番果は早採り（薄いオレンジ背景）
📦 こまめに収穫 → 1株で最大100個！（薄い緑背景）

【下部のまとめ帯】
背景を濃い緑にして白文字で：
「小さい ≠ 弱い　焦らず見守れば、ピーマンは応えてくれる」

【デザインの指示】
- フォントはゴシック体（太め）で統一
- 配色：緑・黄緑・白・オレンジ（ピーマンカラー）
- フラットデザイン、やわらかいイラスト調
- すべてのテキストは日本語で表記
- 文字は読みやすく大きめに
```

---

## 使い方

1. ChatGPT（GPT-4oまたはGPT Images 2.0対応モデル）を開く
2. 上記プロンプトをそのまま貼り付ける
3. 生成された画像をダウンロード
4. note記事やSNS投稿のアイキャッチとして使用
