# GPT Images 2.0 インフォグラフィック生成プロンプト

```
日本語のインフォグラフィックを作成してください。

テーマ：「マルチの下が熱すぎる！小さい苗が枯れる原因と対策」

【レイアウト】
- 縦長（1080×1350px、Instagram/note向け）
- 背景は薄いオレンジ〜黄色のグラデーション（熱のイメージ）
- 上部にタイトル、中央にメインコンテンツ、下部にまとめ

【タイトル（上部）】
大きな太字で：
「マルチの下が熱すぎる！」
その下に小さく：「小さい苗が枯れる原因と正しい対策」

【セクション①：マルチの下で起きていること】
マルチシートと苗のかわいい断面イラスト付き
赤い矢印で「40度超の熱気」がこもっている様子を表現
テキスト：「黒マルチが太陽の熱を吸収 → 下の空気が40度以上に」
背景色：薄い赤/オレンジ

【セクション②：小さい苗 vs 大きい苗】
左右の比較イラスト：
左：小さい苗に熱風が当たり「×」マーク → 「こけて死んでしまう」
右：大きい苗は「○」マーク → 「耐えられる」
背景色：薄い黄色

【セクション③：対策3つ】
3つのアイコン付きカード：
🔧 マルチをピンと張る（隙間をなくす）
🌱 苗の周りはとくに注意
✅ バタつかないよう土でしっかり固定
背景色：薄い緑

【下部のまとめ帯】
背景を濃い茶色にして白文字で：
「マルチは敷くだけじゃダメ。苗を守る技術です」

【デザインの指示】
- フォントはゴシック体（太め）で統一
- メイン配色：オレンジ・赤・茶色・緑（畑カラー）
- フラットデザイン、やわらかいイラスト調
- すべてのテキストは日本語で表記
- 文字は読みやすく大きめに
```

---

## 使い方

1. ChatGPT（GPT-4oまたはGPT Images 2.0対応モデル）を開く
2. 上記プロンプトをそのまま貼り付ける
3. 生成された画像をダウンロード
4. note記事やSNS投稿のアイキャッチとして使用
