# GPT Images 2.0 インフォグラフィック生成プロンプト

```
日本語のインフォグラフィックを作成してください。

テーマ：「自衛隊の秘密組織『別班』とは何か」

【レイアウト】
- 縦長（1080×1350px、Instagram/note向け）
- 背景はダークネイビー〜ダークグレーのグラデーション（ミリタリー調）
- 上部にタイトル、中央にメインコンテンツ、下部にまとめ

【タイトル（上部）】
大きな太字（白文字）で：
「平和ぼけ？その裏に"別班"がいる」
その下に小さく（薄いグレー文字）：「自衛隊の影の諜報組織」

【セクション①：一般的なイメージ vs 現実】
左右に分けた比較レイアウト：
左「一般のイメージ」：🕊️ アメリカに守られている / 自分で守る力がない / 平和ぼけ
右「現実」：🔍 秘密の諜報組織が存在 / 国内外で活動 / 高度な情報管理
背景色：左はグレー、右は濃い青

【セクション②：別班とは】
シルエットのエージェントのイラスト付き
3項目を縦に並べる：
🕵️ 自衛隊内の非公式諜報組織
👤 一般国民に紛れて活動
🔒 存在自体が極秘
背景色：濃い紺

【セクション③：なぜ知られていないのか】
検索バーのイラスト付き
テキスト：「どの検索エンジンでもトップに出てこない」
「情報は意図的に管理されている」
背景色：ダークグレー

【下部のまとめ帯】
背景を赤にして白文字で：
「別班は、あなたのすぐそばにいるかもしれない」

【デザインの指示】
- フォントはゴシック体（太め）で統一
- メイン配色：ネイビー・ダークグレー・白・赤（アクセント）
- フラットデザイン、シリアスなトーン
- すべてのテキストは日本語で表記
- 文字は読みやすく大きめに
```

---

## 使い方

1. ChatGPT（GPT-4oまたはGPT Images 2.0対応モデル）を開く
2. 上記プロンプトをそのまま貼り付ける
3. 生成された画像をダウンロード
4. note記事やSNS投稿のアイキャッチとして使用
