# transcribe スキル

## 前提

- プロジェクトルート: `C:\Users\ami\Downloads\Claude用\ami.kadai`（以降 `$ROOT`）
- 入力フォルダ  : `$ROOT\00ボイスメモ`
- 出力フォルダ  : `$ROOT\01文字起こし`
- アーカイブ先  : `$ROOT\00ボイスメモ\processed`
- 文字起こしスクリプト: `${CLAUDE_SKILL_DIR}\scripts\run.js`

## 処理手順

### STEP 1 — 処理対象ファイルの列挙

`$ROOT\00ボイスメモ` 直下の音声ファイル（.m4a .mp3 .wav .ogg .flac）を列挙する。
`processed` サブフォルダは除外する。

```bash
Get-ChildItem "C:\Users\ami\Downloads\Claude用\ami.kadai\00ボイスメモ" `
  -File -Include "*.m4a","*.mp3","*.wav","*.ogg","*.flac" |
  Select-Object -ExpandProperty FullName
```

対象ファイルが0件なら「処理するファイルがありません」と報告して終了する。

---

### STEP 2 — 各ファイルを順番に処理

以下を1ファイルずつ繰り返す（変数 `$AUDIO` に絶対パスを入れる）。

#### 2-1. 文字起こしデータの取得

**重要**: ダミーテキストや推測内容を使用してはならない。

```powershell
node "${CLAUDE_SKILL_DIR}\scripts\run.js" "$AUDIO"
```

- スクリプトは stdout に文字起こしテキストのみ出力する。
- .txt ファイルが存在すればそれを優先使用し、なければ Whisper で変換する。
- エラーが返った場合はそのファイルをスキップし、エラー内容を報告する。

#### 2-2. メタデータの確定

| 項目 | 値 |
|---|---|
| `日付` | ファイルの更新日時を `YYYY-MM-DD` 形式で取得 |
| `元ファイル名` | 拡張子付きファイル名（例: `memo_0620.m4a`） |
| `タイトル` | 拡張子なしのファイル名 |
| `タグ` | `[文字起こし, 音声]` 固定 |

#### 2-3. AI による整形・分析

取得した文字起こしテキストを分析し、以下を作成する。

1. **要約セクション**: テキスト全体を読み、主要テーマを箇条書きで整理する（3〜5点）。
2. **全文テキスト**: 読みやすく整形した元の文字起こし（改変しない）。
3. **YAMLフロントマター**（日本語キー）:

```yaml
---
タイトル: <元ファイル名（拡張子なし）>
作成日: <YYYY-MM-DD>
元ファイル: <元ファイル名.拡張子>
タグ:
  - 文字起こし
  - 音声
---
```

#### 2-4. Markdown ドキュメントの組み立て

以下の順序で結合する:

```
{YAMLフロントマター}

# {タイトル}

![[{元ファイル名.拡張子}]]

## 要約

{要約箇条書き}

---

## 全文文字起こし

{整形済みテキスト}
```

#### 2-5. ファイル保存

出力先: `$ROOT\01文字起こし\{タイトル}.md`

同名ファイルが既に存在する場合は末尾に `_2`、`_3` と連番を付ける。

#### 2-6. 音声ファイルのアーカイブ

処理完了後、音声ファイルを `$ROOT\00ボイスメモ\processed\` へ移動する。

```powershell
Move-Item "$AUDIO" "C:\Users\ami\Downloads\Claude用\ami.kadai\00ボイスメモ\processed\"
```

---

### STEP 3 — 完了レポート

全ファイルの処理が終わったら以下を報告する:

- 処理成功: N 件（ファイル名一覧と保存先パス）
- スキップ/エラー: N 件（理由）
