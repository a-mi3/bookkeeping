# BlogWriting スキル

文字起こしデータを主軸に、参考資料で裏付けた note.com 用ブログ記事を生成する。

## 前提

| 項目 | パス |
|---|---|
| プロジェクトルート | `C:\Users\ami\Downloads\Claude用\ami.kadai`（以降 `$ROOT`） |
| 音声入力 | `$ROOT\00ボイスメモ` |
| 文字起こし | `$ROOT\01文字起こし` |
| 参考資料 | `$ROOT\articles` |
| 文字起こしスクリプト | `${CLAUDE_SKILL_DIR}\..\transcribe\scripts\run.js` |

---

## 処理手順

### PHASE 1 — 文字起こし（自動前処理）

`$ROOT\00ボイスメモ` 直下に未処理の音声ファイル（.m4a .mp3 .wav .ogg .flac）があるか確認する。

```powershell
Get-ChildItem "$ROOT\00ボイスメモ" -File |
  Where-Object { $_.Extension -match '^\.(m4a|mp3|wav|ogg|flac)$' }
```

- **ファイルがある場合**: transcribe スキルと同じ手順で文字起こしを実行する。
  1. `node` でスクリプト実行（.txt 優先、なければ Whisper）
  2. YAML フロントマター + 要約 + 全文をまとめた .md を `01文字起こし` に保存
  3. 音声を `00ボイスメモ\processed\` へ移動
- **ファイルがない場合**: PHASE 2 へスキップする。

---

### PHASE 2 — 対象ファイルの決定

#### 引数ありの場合

`$ARGUMENTS` で指定されたファイル名を `01文字起こし` から探す。
拡張子 `.md` は省略可能。部分一致で検索する。

#### 引数なしの場合

`01文字起こし` 内の文字起こしファイルを一覧し、ユーザーに選択を求める。
`_note` 付きの記事ファイルは除外する。

```powershell
Get-ChildItem "$ROOT\01文字起こし" -Filter "*.md" |
  Where-Object { $_.Name -notmatch '_note' }
```

---

### PHASE 3 — 参考資料の収集

`$ROOT\articles` フォルダ内の全 Markdown ファイルを読み込む。

```powershell
Get-ChildItem "$ROOT\articles" -Filter "*.md" -Recurse
```

対象の文字起こし内容に関連するキーワードを抽出し、articles 内から関連する資料を特定する。
関連資料が見つからない場合でも記事生成は続行する（参照なしで記事を書く）。

---

### PHASE 4 — 記事の生成

以下のルールで note.com 用ブログ記事を生成する。

#### 記事構成の原則

1. **主軸は文字起こしデータ**: ユーザーの思想・体験が記事の中心。参考資料はあくまで裏付け。
2. **読者に語りかける文体**: 「です・ます」調。体験談として書く。
3. **構造**: タイトル → 導入 → 本論（2〜4セクション）→ まとめ → ハッシュタグ

#### タイトル

- **【】で注目ワード**を入れる（例：【6月中旬】）
- 読者の疑問や不安を代弁する形にする
- 30〜50文字程度

#### 本文

- 文字起こしの内容を「私の体験」として自然な文章に再構成する
- 参考資料を根拠として本文に織り込む
- **出典リンクは必ず情報元の Web URL を記載する**（Obsidian リンクではなく `https://...` の URL）
- リンク形式: `[サイト名](https://example.com/path)` — note エディタでクリック可能な形式にする
- 引用は `>` ブロックを使う

#### フォーマット

- **YAML フロントマターは付けない**（note では不要）
- **Obsidian 記法 `![[]]` は使わない**（note では動作しない）
- クリーンな Markdown のみ使用する（見出し `#`、太字 `**`、リスト `-`、引用 `>`、リンク `[]()`）
- 末尾にハッシュタグを `#タグ名` 形式で5〜8個付ける

---

### PHASE 5 — ファイル保存

出力先: `$ROOT\01文字起こし\{元ファイル名}_note.md`

- `{元ファイル名}` は文字起こしファイルの拡張子なしのファイル名
- 同名ファイルが既に存在する場合は**上書きする**（記事の再生成を想定）

---

### PHASE 6 — 完了レポート

| 項目 | 内容 |
|---|---|
| 元ファイル | 使用した文字起こしファイル名 |
| 参考資料 | 使用した articles 内のファイル数と名前 |
| 出力先 | 保存した note 記事ファイルのパス |
| タイトル | 生成した記事タイトル |
