# ネオンピンク・華やかコスメ型

## 型
- サイズ：1:1の正方形。
- 色：黒・鮮やかなピンク・白。装飾はシルバー。
- 文字：左半分に極太の明朝系文字を積み重ねる。白とピンクで強弱を付け、最後の短い言葉を最大にする。左上に傾いたピンクの小ラベル。
- 必須要素：左上の短いラベル、左側の大見出し、右側の主役、左下のコスメ、宝石・チェーン・斜めのネオン光。お手本の顔写真は配置だけを引き継ぎ、中身は含めない。
- 禁止事項：実在企業のロゴ、他人の顔写真を使わない。長い説明文・細かい文字・広い余白を増やさない。日付・名前は必須にしない。APIキーやパスワードをチャットやファイルに書かない。

## 手順と出力
1. お題を受け取り、この型に合わせて短い見出しと主役を決める。人物の顔の代わりに、お題に合う商品や物を使う。未指定の日付・名前などを事実として作らない。
2. 画像生成に渡すプロンプトを「日本語の指示」「英語の生成用プロンプト」の2段で出す。両方に同じ型と表示文字を指定する。
3. 「プロンプトだけ」と言われた時、または画像生成の道具が使えない時は、プロンプトの文章だけを返す。
4. 画像生成の道具が使える時は、実際に使うサービス・モデルについて1枚あたりの料金と生成枚数・合計の見積もりを示し、利用者のOKを待つ。料金を確認できない場合は推測で金額を作らず、その旨を伝えて生成を保留する。
5. 見積もりへのOK後は、承認された範囲で画像生成を実行し、完成画像を渡す。型に合っているかと文字の誤りを確認する。追加費用が必要な再生成は新たに見積もりとOKを得る。

AIが行ってよい範囲：プロンプト作成まで自動で行い、画像生成は見積もりへのOK後に行う。公開・投稿はしない。
